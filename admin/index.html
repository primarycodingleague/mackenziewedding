One-time setup needed

The dashboard and live RSVP collection need the site's database connected. This takes about five minutes:

  1. Create a free project at supabase.com (any project name, choose a region near you).
  2. Open the project's SQL Editor, paste the contents of setup.sql from this site's GitHub repository, and click Run.
  3. In Authentication → Users, click Add user and create a login for each of you (email + password).
  4. In Authentication → Sign In / Up, turn off "Allow new users to sign up".
  5. In Project Settings → API, copy the Project URL and the anon public key into config.js in the GitHub repository (edit the file on github.com and commit).

A minute or two after committing, reload this page and log in.
